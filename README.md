# DeFi Operations Work Samples for Sentora

Three independent work samples built around Sentora-curated Morpho vaults.

**Live site:** https://jthom-crypto.github.io/sentora/

| # | Project | What it covers |
|---|---|---|
| 1 | [Institutional DeFi Operations Desk](https://jthom-crypto.github.io/sentora/ops-desk/) | Day-to-day client support across three Sentora vaults: positions, reconciliation, transactions, liquidity, exceptions, and a daily report. |
| 2 | [DeFi Treasury Operations](https://jthom-crypto.github.io/sentora/treasury-ops/) | Deploying a client's PYUSD into Sentora vaults: deployable cash, vault comparison, policy checks, exposure, and an approval record. |
| 03 | [PRIME Market Operations Monitor](https://jthom-crypto.github.io/sentora/prime-monitor/) | Monitoring a Sentora-curated vault that lends PYUSD against PRIME: allocations and withdrawal liquidity, borrower stress, data checks, and approval tracking. |

## Data

Vault and market data come from public APIs (Morpho, CoinGecko), with a dated fallback snapshot if an API is unavailable. Clients, positions, policies, and approvals are simulated. Every value is labeled observed, estimated, or simulated.


Independent work by Justin Thom. Not affiliated with or endorsed by Sentora or Morpho.
